# موقع نتائج جامعة اللاذقية — نظام الاعتراضات

## تشغيل الموقع
1. ثبّت Python 3.10 أو أحدث.
2. افتح Terminal/CMD داخل هذا المجلد.
3. شغّل:
   `python server.py`
4. افتح:
   `http://localhost:8000`

السيرفر ينشئ قاعدة البيانات تلقائياً في:
`data/appeals.db`

## رابط API
موجود في `config.js`:
`const API_BASE_URL = "http://localhost:8000/api";`

عند رفع الـAPI على استضافة أخرى غيّر هذا الرابط إلى رابط الـAPI الجديد.

## مفتاح لوحة التحكم
في `config.js` غيّر:
`const ADMIN_API_KEY = "CHANGE-ME-ADMIN-KEY";`

وفي بيئة الإنتاج يُفضَّل وضع نفس المفتاح في متغير البيئة `ADMIN_API_KEY` على السيرفر وعدم نشر المفتاح الحقيقي داخل ملفات الموقع العامة.


## الإضافات الجديدة
- بوابة **مقارنة بين طالبين** من الصفحة الرئيسية: يمكن إدخال اسم الطالب أو رقم الاكتتاب، وتظهر كل علامات الفصلين مع المعدل العام جنباً إلى جنب.
- زر **📊 عرض الرسم البياني** بجانب المعدل العام في صفحة النتيجة، ويعرض جميع المواد ذات العلامات الصادرة بأعمدة أفقية ونسبة كل مادة من 100.
- عند البحث عن نتيجة تظهر شاشة **جارِ استخراج نتيجتك ⏳** لمدة ثانيتين قبل فتح النتيجة.
- الإشعارات أصبحت محفوظة في **SQLite على السيرفر** عبر جدول `notifications`، لذلك الإشعار الذي يرسله المدير من لوحة التحكم لا يعتمد على localStorage الخاص بجهاز واحد، بل يُقرأ من نفس قاعدة البيانات لجميع زوار الموقع.
- عند أول تشغيل للسيرفر تُنشأ قاعدة البيانات تلقائياً داخل `data/appeals.db`.
